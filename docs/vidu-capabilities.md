# Vidu S2 在《雨停之前》中的能力与接入

核对日期：2026-10-17。官网参数页优先于 GitHub 早期说明。
官方来源：https://platform.vidu.com/vidu-stream/doc/s2-avatar/realtime/parameters
官方示例：https://github.com/shengshu-ai/vidu-s-api

| 能力 | 游戏用途 | 本轮状态 |
|---|---|---|
| RTC 原生语音 + VAD | 说完自然回应，麦克风静音，不需要手动发送 | 已接入，摄像头始终关闭 |
| audio.enable_transcription，type9/type10 | 用户语音自动触发剧情，实际角色字幕进入画面 | 已接入；已收到真实角色字幕。type9 也回传已发送文本，已过滤并避免重复推进；真人连续说话仍需玩家实测 |
| type11 prompt_operation.images[] | 道具、换装、背景，1–3张参考图 | 本轮一次1张；明确kind，base64图，无公网托管要求；影院背景参考图已收到真实type12成功确认，最终视觉保真未单独量化 |
| type7 interrupt | 主动打断长回答 | 已接入 |
| type97 session_update | 切剧情节点更新角色当前知识，防止旧场景惯性 | 已接入当前场景persona，type98反馈 |
| enable_recording + /live/v1/lives/:id/recording | 回忆录像、播放、下载 | 已接入并下载真实MP4；通常结束后2分钟生成，官方URL24小时有效。本地分段下载带网络重试，完成后长期保存 |
| idle_motion | 自然等待动作 | 本轮使用默认动作库 + intelligent推荐 |
| action.enabled | 用户言语触发动作 | 本轮使用平台默认库；自定义动作库待按剧情制作 |
| 音色与声音克隆 | 两位女主专属声线 | 后续：先选音色，再用获授权配音素材克隆；provider需一致 |
| memory_retrieval | 跨章节记住玩家偏好与共同经历 | 后续：按玩家+角色隔离，按已解锁信息写入，避免剧透 |
| knowledge_retrieval | 从剧本与线索库检索已知事实 | 后续：按剧情节点过滤检索，不上传完整未解锁答案 |
| 组件版/离线版 | 严格台词、配音、预生成转场 | 后续：比实时版自由对话更可控，需要独立链路 |
| S2 Editing | 玩家摄像头风格化、换装、主体替换 | 暂不接入，当前游戏是角色交互，不需要采集玩家画面 |

## 行为边界
- Vidu 自带对话模型负责角色自由交流；游戏意图识别默认同义表达、谨慎模糊匹配和三轮兜底，可接独立模型增强。
- 官方对参考图的确认表示接受，不保证立即完成视觉变化；界面不把发送成功当作最终画面验收。
- 背景/服装互动仅影响表演，不授予线索或改变剧情地点逻辑。
- 回忆保存在本机 `.data/memories`；首次升级前未开启录制的旧通话无法补录。删除回忆移除本机副本，不调用平台删除接口。
