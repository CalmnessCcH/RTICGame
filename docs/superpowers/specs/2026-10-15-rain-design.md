# 《雨停之前》第一章设计

用户已同意制作两位成年女主、两个场景的第一人称互动剧情原型，并选择现代都市悬疑恋爱与电影写实。目标是能玩完一章，并验证 Vidu S2 的接入，而非只做界面。

## 体验与内容
- 主角周屿，28 岁，声音修复师。回到临海城，收到失约旧友的邀请。
- 林知夏，27 岁，声音档案整理员；温柔克制，重视承诺。地点：夜航咖啡馆。
- 沈听澜，29 岁，独立声音记者；敏锐直接，不接受未经核对的结论。地点：星海影院放映室。
- 第一章《迟到的来信》含 9 个交互节点与 3 个结果。共同悬念：三年前停电夜的一段录音被截断。
- 真相不是某位女主简单说谎：两人分别保存了录音与出入记录；玩家必须同时尊重私人情感和证据完整性。
- 单人中景、人物看向玩家、电影画面占主要区域。墨绿黑、暖金、象牙白；标题宋体与功能无衬线字体。低调雨与胶片元素。

## 系统边界
- React + TypeScript DOM 适合本作以影像和对话为核心的交互；不引入 3D 引擎。
- src/game：纯数据剧情图、类型、纯函数转移和输入解释。存档不包含媒体连接或密钥。
- 文字输入和推荐选项统一生成 action；规则验证当前可用动作后才转移。重复收集证据不得重复刷关系。
- 本地规则模式明确标注为规则试玩，不宣称开放域 AI；可选服务端 LLM 按当前节点可用动作做语义解释，禁止输出任意跳转。
- 浏览器语音输入按需启用，识别结果进入文本框供确认；无支持或权限失败可继续文字游玩。
- localStorage 自动保存，导入严格校验版本、节点、证据、关系边界、日志长度；损坏存档不导致崩溃。
- S2 首版用实时版验证影像链路。persona 仅包含角色当前已知信息；游戏仍是剧情状态唯一决定者。实时版对逐字台词和背景一致性的保证待实测；组件版作为后续升级。
- Node 服务端保存 Vidu key、代理创建及控制 WS。客户端只接收临时 RTC 凭据；不默认发布麦克风或摄像头。
- 单次实时会话默认上限 120 秒；每次主动启动，在退出、换人物、页面隐藏、WS 异常或超时后挂断。最多一个运行会话；服务退出清理。创建后无人连接也必须回收。
- 仅监听 127.0.0.1；同源校验；不发布公网。

## 验收
- 两条人物线能推进，3 个结局可达；条件未满足不能直接到真相结局；离题不跳节点；否定句不误选肯定动作。
- 刷新恢复存档；重新开始有确认；日志、线索、人物档案可打开关闭；移动端可输入与选项。
- 构建和规则测试通过，浏览器实际检查主要流程、布局及控制台。
- 真实 S2 短会话记录创建、初始化、出流/失败、文本响应和终止结果。没有测到的能力明确列出。
