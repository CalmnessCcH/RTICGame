# 实时剧情体验升级设计

用户要求：直接语音交流；宽容的剧情识别及多轮兜底；画面内统一字幕；官方 S2 道具/换装/背景互动；视频回忆；设置密钥；评估更多能力。用户明确要求先列计划再整改，因此按本文件直接执行，不增加重复审批。

采用原生 RTC 麦克风音频，摄像头始终关闭。创建前请求麦克风，拒绝后降级文字。audio.enable_transcription 返回 type 9/10，用最终用户转写驱动剧情，同一句不重复发送给 Vidu。文本和按钮保留。通话字幕采用真实角色转写；本地剧情结果只负责分支提示。离开页面/结束释放麦克风。

匹配优先当前可用动作：明确意图和否定保护、同义表达与谨慎模糊匹配、已配置独立 LLM 时语义判断。无匹配连续 3 轮选择当前节点显式安全默认动作；不授予未满足条件的隐藏线索，不强迫恋爱结局。旧存档迁移 unmatchedTurns=0。

对话不增加独立聊天框。剧情字幕区显示玩家最后一句、角色实时转写；输入框为无边框画面内输入。实时回复时剧情可自动过渡同人物节点，跨人物仍结束旧会话。

参考图使用官网 2026-10-17 查询到的 type11 prompt_operation.images[] (image_uri,image_id,kind,user_text)，支持 object/garment/background，type12确认。不把已发送称为已生效。支持本地图片 base64（3MB内）、内置参考图、remove 恢复，单次操作与超时反馈。

回忆使用官方 enable_recording + 结束后 recording API。持久化 .data/memories/ 元数据与录制 MP4，服务端下载仅来自官方接口返回的 HTTPS 链接，限制大小与时间；生成中可刷新，失败可重试。保留会话摘要、节点、字幕、实际计费，重启可恢复。UI 展示生成中/可播放/失败；支持播放、下载、删除。已过期的下载链接每次从官方重新查询。

设置：同源本地 POST /api/settings；只接收合法 Vidu key 和固定区域；原子写 .env mode0600，不回显完整 key。活跃/创建中的会话禁止改 key，新的连接读取新值。提供可选独立 LLM 配置用于语义增强，留空保留已有密钥。

新增能力本轮：VAD自然停顿、转写、录制、idle_motion、session_update当前场景人设。后续：专属音色/声音克隆、受控长期记忆/知识库、动作库、组件版严格配音。官网优先于 GitHub 旧协议。

验收：自动测试覆盖否定/模糊/三轮兜底/门槛、设置秘密与热更新、音频生命周期、字幕去重、参考图校验/ack、录像持久化与恢复。浏览器检查桌面手机、设置、统一字幕、互动、回忆。付费测试单会话短时，未实际验证的能力明确记录。
