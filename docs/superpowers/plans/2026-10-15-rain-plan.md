# Rain Chapter Implementation Plan

**Goal:** Deliver a playable Chinese cinematic story chapter and a bounded, server-proxied Vidu S2 trial.
**Architecture:** Pure story engine + React interface + local Node API. Pre-generated still assets remain the fallback when live media is unavailable.
**Tech Stack:** React, TypeScript, Vite, Express, ws, Vitest.
**Spec:** ../specs/2026-10-15-rain-design.md

## Global constraints
Adult original characters, two locations, no API keys in frontend, no arbitrary model-controlled state transitions, 120-second live cap, loopback only. User authorized implementation and supplied Vidu credentials; execute locally in this session.

## Review focus
1. Invalid and corrupted saves recover without granting nonexistent clues.
2. Negative or ambiguous input cannot silently select a contradictory action.
3. Double submits do not apply stale turns after scene changes/reset.
4. Every live connection path cleans up billable resources, including abandoned starts.
5. Secret values never appear in status, asset bundle, client error messages or saved games.
