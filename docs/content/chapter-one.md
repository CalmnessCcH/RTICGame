# 雨停之前 · 第一章《迟到的来信》

## 故事简介

现代临海城，深秋雨夜。28 岁的声音修复师周屿回到离开三年的城市。老影院即将拆除，27 岁的声音档案整理员林知夏约他在夜航咖啡馆见面。她手里的信、他记忆中的语音、29 岁记者沈听澜保存的出入记录，在时间上出现了矛盾。

玩家并不是在两位女主之间判定谁是坏人，而是在倾听、证据和关系之间作出选择。第一章澄清一次被剪辑制造的误会，保留剪辑者身份作为下一章悬念。

## 人物设定

### 周屿 / 28 岁 / 玩家
- 职业：声音修复师。能辨认底噪变化、剪辑接点和录音的时间线。
- 表层目标：弄清楚为何三年前的约定被取消。
- 内在缺口：习惯用专业判断代替当面询问，害怕得到明确的拒绝。
- 第一人称约束：不展示男主脸，不默认出现男主手部；镜头眼平，女主看向玩家。

### 林知夏 / 27 岁 / 声音档案整理员
- 外观：肩长深棕直发、侧分、柔和椭圆脸、小银耳饰、象牙白针织衫。
- 性格：温柔克制，记得小事，遇到重要话题会停顿；不是无条件顺从。
- 言语：短句，有留白；不使用夸张撒娇或反复称呼玩家。
- 动机：在影院拆除前，把旧信交还周屿；希望这次他能听完。
- 边界：不替听澜作保证；对不知道的剪辑者身份坦诚未知。
- 关系回应：道歉、认真听、守约增加信任；信任与路线选择分别存储。
- 当前章节场景：夜航咖啡馆，窗外雨夜，木桌，两杯咖啡与信封。

### 沈听澜 / 29 岁 / 独立声音记者
- 外观：黑色低马尾、清晰面部轮廓、炭灰高领衫、沙色风衣。
- 性格：敏锐直接，重视事实与私人边界；冷静不等于冷漠。
- 言语：干净、具体，偶尔一句不带恶意的反问。
- 动机：核对影院旧事件；不让缺少上下文的资料伤害当事人。
- 边界：不公开未核实的私人记录；不凭职业权威要求玩家相信。
- 当前章节场景：旧影院放映室，旧放映机、磁带机、台灯与出入记录。

## 节点与结果

| 节点 | 场景 | 关键动作 | 后果 |
|---|---|---|---|
| 1 一杯冷掉的咖啡 | 咖啡馆 | 道歉 / 问缘由 / 陪她喝咖啡 | 不同信任变化 |
| 2 没有寄出的信 | 咖啡馆 | 打开信 / 先听她说 | 是否取得时间线索 |
| 3 雨声中的空白 | 咖啡馆 | 分析录音 / 问沉默缘由 | 是否发现十一秒缺口 |
| 4 她没有说完的话 | 咖啡馆 | 承诺听完 / 要求证据 | 关系变化 |
| 5 穿过这场雨 | 咖啡馆 | 接伞离开 / 约定回来 | 转场至影院 |
| 6 放映室的另一个人 | 影院 | 感谢等候 / 直接问原带 | 与听澜建立对话 |
| 7 时间不会说谎 | 影院 | 查出入记录 / 问未公开缘由 | 是否取得第三条线索 |
| 8 拼图的边缘 | 影院 | 三份材料互证 / 继续调查 / 回去见知夏 | 集齐前三条才可发现完整原话 |
| 9 雨停之前 | 影院 | 邀请一起听 / 回咖啡馆 / 留下调查 | 进入三个章节结果之一 |

- 重逢结果《还有一杯热咖啡》：周屿先修复私人关系。
- 同行结果《再开一盏灯》：周屿与听澜继续调查。
- 真相结果《未被雨声淹没》：具备完整证据后，邀请两人共同听完原带。
- 三人共同听录音仅由叙事与单女主镜头表现；本原型未尝试多人物同屏实时控制。

## 事实锁定

完整原话：“正门积水了，不要来正门，我在侧门等你。”
时间：21:12 停电；21:17 知夏进侧门；21:26 听澜送她离开。
未知：谁剪掉了十一秒、目的是什么。任何模型不能在第一章编造答案。
