# 雨停之前 / Before the Rain Ends

一个本地运行的第一人称都市悬疑恋爱互动剧原型。原创成年角色、电影写实画面、可验证的剧情分支，以及可开启的 Vidu S2 实时角色接入。

## 运行

需要 Node.js 22.12+。

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:8787 。本地服务只绑定回环地址。

生产预览：

```bash
npm run build
npm start
```

- 林知夏（27 岁）、沈听澜（29 岁）两位女主；夜航咖啡馆、星海影院两个地点。

- 人物信任、线索条件、对话回顾、自动存档、JSON 导入导出、字号调整、可选系统朗读。
- 2 张第一人称剧情图、2 张单人角色参考图、2 张空场景参考图，见 public/assets。
- 支持桌面与手机布局、键盘操作及 reduced-motion。

## Vidu S2

密钥只存在服务端 `.env`，已经被 `.gitignore` 排除，不能放进 `VITE_*` 环境变量或提交仓库。

```dotenv
VIDU_API_KEY=你的密钥
VIDU_HOST=api.vidu.com
LIVE_MAX_SECONDS=120
```

本次用户密钥属于国际站，已在本机配置；Key ID 不需要额外传入。中国站密钥则使用 `api.vidu.cn`。不要混用区域。

进入故事，点击右上角“开启实时表演”。Node 服务端创建 S2 会话并代理控制 WebSocket，浏览器通过官方 AliRTC 7.1.9 接收视频；不会自动上传摄像头或麦克风。文本指令由游戏发送，语音输入先经浏览器转写。

默认每次实时会话上限 120 秒。结束按钮、切换角色、隐藏页面、断线、启动超时和本地服务退出均包含清理；创建后 30 秒没有客户端连接也会回收。密钥不返回浏览器，临时 RTC 凭据仅用于当前会话。

**真实调用结果（2026-10-16）：**充值后国际站已成功创建会话，控制连接就绪并已发送剧情指令。浏览器验收被摄像头权限提示阻断：SDK 默认在加入频道时开启本地音视频，现已在加入前明确关闭音视频发布，并将接收能力检测放在付费会话创建前。两次已创建会话均确认 `ended`，分别结算 27 秒 / 41 积分、50 秒 / 75 积分，累计 116 积分。真实画面播放、唇形和剧情回应仍待修复后的浏览器验收。

本轮采用 **Avatar 实时版实验接入**，方便验证影像链路。模型自由口播可能与预定字幕有差异，游戏状态始终由本地规则决定。正式版若要求逐字台词、统一 TTS 与严格中断控制，应升级至 Avatar 组件版并实测。

调试状态：`GET /api/status`，已创建会话的非敏感报告：`GET /api/live/reports`。报告保留于本地进程内，最多 20 条。

## 开放式语言理解（可选）

未配置语言模型时，界面明确标记“规则剧情试玩”。它支持明确意图的有限识别与推荐选项，不是开放域聊天 AI；语义含糊时停留原场景，否定句不会直接触发对应肯定动作。

可在 `.env` 中配置 OpenAI 兼容接口，重启服务后启用：

```dotenv
LLM_API_KEY=你的语言模型密钥
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=你账号可用的模型名
```

语义服务只能从当前节点允许的动作中选择。无效输出、超时或服务异常回退本地规则。模型只能获得当前节点台词与动作，不会收到整个剧本的隐藏真相。本轮没有配置独立语言模型，因此尚未实测此扩展。

## 目录

- `src/game/story.ts`：可执行剧本、人物、线索、动作和结局。
- `src/game/engine.ts`：剧情转移、意图规则、存档校验。
- `src/lib/live.ts`：实时视频组件、取消、指令与 SDK 生命周期。
- `server/live.ts`：S2 服务端鉴权、会话代理与时长限制。
- `docs/content/chapter-one.md`：故事与人物设定。
- `docs/content/*prompts.md`：内置 image_gen 使用的完整提示词。
- `docs/verification.md`：实测证据与未验证事项。
