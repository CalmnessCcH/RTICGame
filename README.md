# 雨停之前 / Before the Rain Ends

一个本地运行的第一人称都市悬疑恋爱互动剧原型。原创成年角色、电影写实画面、可验证的剧情分支，以及可开启的 Vidu S2 实时角色接入。

## 运行

需要 Node.js 22.12+。

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:8787 。本地服务只绑定回环地址。

生产预览：

```bash
npm run build
npm start
```

## 第一章已有内容

- 林知夏（27 岁）、沈听澜（29 岁）两位女主；夜航咖啡馆、星海影院两个地点。
- 9 个交互节点、4 条线索、3 个章节结果；重要回应单独展示后再继续剧情。
- 文字输入、推荐选项；通话使用 RTC 原生语音，非通话的浏览器语音识别自动发送。
- 同义表达、模糊匹配、否定保护；连续 3 轮未命中进入默认分支，保留线索门槛。
- 玩家回应与角色实际字幕进入剧情画面；道具、服装、背景参考图互动；视频回忆。
- 人物信任、线索条件、对话回顾、自动存档、JSON 导入导出、字号调整、可选系统朗读。
- 2 张第一人称剧情图、2 张单人角色参考图、2 张空场景参考图，见 public/assets。
- 支持桌面与手机布局、键盘操作及 reduced-motion。

## Vidu S2

密钥只存在服务端 `.env`，已经被 `.gitignore` 排除，不能放进 `VITE_*` 环境变量或提交仓库。

```dotenv
VIDU_API_KEY=你的密钥
VIDU_HOST=api.vidu.com
LIVE_MAX_SECONDS=120
```

本次用户密钥属于国际站，已在本机配置；Key ID 不需要额外传入。中国站密钥则使用 `api.vidu.cn`。不要混用区域。

进入故事，点击右上角“开启实时表演”。Node 服务端创建 S2 会话并代理控制 WebSocket，浏览器通过官方 AliRTC 7.1.9 接收视频。创建前申请麦克风权限，获准后直接发布音频，摄像头始终关闭。语音转写自动驱动剧情，无需再次发送；拒绝麦克风时仍可文字交流。

默认每次实时会话上限 120 秒。结束按钮、切换角色、隐藏页面、断线、启动超时和本地服务退出均包含清理；创建后 30 秒没有客户端连接也会回收。密钥不返回浏览器，临时 RTC 凭据仅用于当前会话。

**当前验收记录（2026-10-17）：**已收到真实 1344×768 视频和角色字幕，结束后音轨释放。网络失败会显示状态并提供重试。完整测试与账单见 `docs/verification.md`。

本轮采用 **Avatar 实时版实验接入**，方便验证影像链路。模型自由口播可能与预定字幕有差异，游戏状态始终由本地规则决定。正式版若要求逐字台词、统一 TTS 与严格中断控制，应升级至 Avatar 组件版并实测。

调试状态：`GET /api/status`，已创建会话的非敏感报告：`GET /api/live/reports`。报告保留于本地进程内，最多 20 条。

官方参考：
- https://github.com/shengshu-ai/vidu-s-api
- https://platform.vidu.com/vidu-stream/doc
- https://platform.vidu.com/vidu-stream/doc/s2-avatar/component/parameters

## 开放式语言理解（可选）

未配置语言模型时，界面明确标记“规则剧情试玩”。它支持同义表达和模糊匹配；语义含糊时先停留当前场景，连续 3 次未匹配进入默认分支。否定句不会直接触发对应肯定动作。Vidu 的角色自由对话与游戏剧情判断是两层系统。

可在游戏设置里配置 OpenAI 兼容接口，保存后新请求立即使用；也支持 `.env`：

```dotenv
LLM_API_KEY=你的语言模型密钥
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=你账号可用的模型名
```

语义服务只能从当前节点允许的动作中选择。无效输出、超时或服务异常回退本地规则。模型只能获得当前节点台词与动作，不会收到整个剧本的隐藏真相。本轮没有配置独立语言模型，因此尚未实测此扩展。

## 目录

- `src/game/story.ts`：可执行剧本、人物、线索、动作和结局。
- `src/game/engine.ts`：剧情转移、意图规则、存档校验。
- `src/lib/live.ts`：实时视频组件、取消、指令与 SDK 生命周期。
- `server/live.ts`：S2 服务端鉴权、会话代理与时长限制。
- `docs/content/chapter-one.md`：故事与人物设定。
- `docs/content/*prompts.md`：内置 image_gen 使用的完整提示词。
- `docs/verification.md`：实测证据与未验证事项。

## 新增入口

- **设置**：修改 Vidu API key、区域和可选语义模型。空白密钥保留原值，结束当前通话后才能修改；保存到服务端私有 `.env`。
- **通话 → 道具 · 换装 · 背景**：内置 5 个选择，也可上传 3MB 以内 PNG/JPEG/WebP。支持撤销；官方确认表示已接受，最终视觉效果取决于模型。
- **回忆**：新版通话自动录制，通常结束约两分钟后生成。本地下载至 `.data/memories`，可播放、下载、删除、刷新。重启后未完成的下载可手动刷新；旧版未录制通话无法补录。
